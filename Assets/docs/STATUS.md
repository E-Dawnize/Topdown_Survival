更新于 2026-10-29 · 对应迭代 0 结束时

## 一句话

工程骨架已经立起来，能在 Unity 里编译、生成四个场景、按 Play 跑起来并加载配置，但**还不能玩**：没有玩家移动，没有敌人，没有波次。

## 能做什么

跑 `python tools/export_config.py`，改 Excel 里的数值，导表会校验并生成 JSON。
Unity 里菜单生成四个场景，按 Play 能进游戏，Console 打出配置版本和各表条数，F1 有调试覆盖层。
在 EditMode 里跑事件总线的 15 项测试。

## 不能做什么

进游戏没有可操作的角色，场景里只有一个静止的胶囊占位。没有敌人、没东西可打。

## 已知问题

1. 场景由 SceneBuilder 生成并已进仓。改生成参数（地面尺寸、相机角度）后要重跑菜单，不要手改场景文件。
2. 输入用代码构建 ActionMap，改键要改代码。I4 做按键自定义时迁回 `.inputactions` 资产。
3. 三个包（Input System / Cinemachine / Newtonsoft）首次打开需要联网下载。
4. 没有任何美术资源，全部是 Unity 内置几何体加材质颜色。
5. `Assets/Settings` 下两个 URP 资产被 Unity 自动从版本 9 升到 11，字段变多了，这是编辑器行为不是手工改的。

## 下一步

迭代 1 有 11 个任务，但顺序不能乱。先做的四件：

1. 玩家移动 + Cinemachine 跟随 + 边界 clamp，手感按"输入到位置变化 ≤ 1 帧"验收。
2. StatBlock 与伤害管线，带单测。属性三乘区和伤害顺序必须先钉死，否则后面所有数值都调不准。
3. 空间哈希 + 200 敌人压测。这是整个技术方案的赌注，压不过就要换路线，越早知道越好。
4. 两把武器（弓箭与砍刀）。

武器的手感依赖命中反馈，命中反馈依赖稳定的帧率，所以排在压测之后。
