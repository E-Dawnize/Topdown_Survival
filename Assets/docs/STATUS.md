# 项目现状

更新于 2026-10-31 · 对应可玩 demo 收尾

## 一句话

从主菜单进一局，打三波、捡金币、逛商店、招旅伴、吃羁绊、死亡结算、重开，流程是通的。
但这一整条只在命令行编译和外部测试 harness 下验证过，**Unity 里一次都没跑过**。

## 能做什么

- 主菜单进 Run 场景，自动开始第一波。
- 玩家移动与冲刺（0.15 秒无敌、2 秒冷却），60Hz 固定步长模拟，渲染按实际帧率插值。
- 自动开火：弓箭索敌、穿透、暴击、距离衰减；砍刀扇形判定带伤害窗口。
- 敌人追击、邻格分离、接触伤害，三种怪。
- 命中反馈：受击变亮、击退、hitstop、震屏、屏幕红闪。
- 金币与心的掉落、磁吸拾取。
- 每波结束开商店，6 格加权抽卡（带保底），键盘买、刷新、关店。
- 旅伴跟随、武器绑定、重复购买升级、阵营羁绊（2 件一级、4 件二级）。
- 死亡或打完最后一波出结算面板，Enter 重开、Esc 回主菜单。

## 不能做什么

- 没有美术，全是内置几何体加颜色。
- 配置表只有 3 波、4 件道具、3 个旅伴、3 种敌人，所以 4 件羁绊和 4 人队伍实际到不了。
- 触发型道具（香水、弹簧、篝火这些）买得到但只生效属性，`EffectType` 没接。
- 没有 BOSS，`BossId` 字段没用上。
- 没有音频、没有局外解锁、没有无尽模式。

## 已知问题

1. 配置表内容太少：4 件道具撑不满 6 格去重要求，现在每间商店都会把紫金摆出来；3 个旅伴每阵营一个，4 件羁绊到不了。
2. 距离衰减公式恒为 1.0：锁定目标一定在射程内，而射程内不衰减。公式有单测，实际不生效。
3. 触发型道具的 `EffectType` 未接，买这些道具只扣钱。
4. 玩家站着不动被 50 个敌人围住约 2.5 秒会死，数值未调过，I1-11 的压力场景就是这个量级。
5. 商店买/刷共用战斗随机流，加刷怪逻辑会挪动暴击序列。
6. 主菜单是运行时搭的，没挂到场景里那个空的 `MenuRoot` 上。

## 下一步

1. 在 Unity 里打开并按 Play，把整条流程走一遍。这是当前最大的未知。
2. 补配置内容：5 波、每品质 ≥6 件道具、每阵营 ≥2 个旅伴。
3. 调数值：让 50 敌场景里能活下来，波次强度曲线按 GDD 填。
4. 接 `EffectType`，让触发型道具真的有效果。
5. BOSS 波与 `BossId`。
