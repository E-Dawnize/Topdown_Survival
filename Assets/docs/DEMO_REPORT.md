## 4 修复的缺陷

全部是既有实现与文档不符，不是新代码写错：

1. `UnitPrefabMap` 里 HudCanvas 的 fileID 指向预制体内部的 Hint 子节点，实例化出来只有一张 Image，`GetComponent<HudView>()` 永远为 null。
2. `EventBusTests.ManySubscribersAllReceive` 从未真正通过：循环里的 lambda 捕获同一闭包，50 次订阅是同一个委托实例，被 `EventChannel` 去重成一个。`STATUS.md` 里"15 项断言全通过"这句话不成立。
3. `DamageResolver` 负护甲在 `armor < -50` 时 `armor/(armor+50)` 变正数，clamp 后成了满减伤。
4. 砍刀命中不发 `UnitDamaged`，近战打中既没有定格也没有震屏和受击变亮。
5. 重开一局时 `RunState` 金币与波次不归零；`ShopController` 重置只清商品列表、没从 `StatBlock` 回滚道具加值，第二局开局就比第一局强。

## 5 已知偏差

这些是实现与文档/设计不一致，已经在代码注释或 `TECH_DESIGN.md` 里写明，需要你判断是否接受：

| 偏差 | 现状 | 影响 |
|---|---|---|
| 距离衰减 | 恒为 1.0 | 锁定目标必在射程内，公式有单测但运行时不生效，是死代码 |
| `Pierce` 语义 | 命中目标总数（1 = 只打第一个） | 与"额外穿透数"的常见理解相反 |
| `SpreadDeg` | 远程是相邻弹道夹角，近战是扇形半角 | 一个字段两种含义 |
| 暴击时机 | 一次扳机掷一次，多发弹道同暴击 | 与 8.2 原写的"每发单独"不同，已改文档 |
| 随机流 | 战斗、刷怪、掉落、商店共用一条 | 加刷怪逻辑会挪动暴击序列，"两流分离"没实现 |
| 刷怪与敌人分离 | 旅伴不参与敌人分离力、不被敌人推动、不夹场地边界 | 墙边可能挤出画面 |
| 道具表 | 4 件，撑不满 6 格去重 | 每间商店都会摆出紫金 |
| 旅伴表 | 3 个，每阵营 1 个 | 4 件羁绊实际到不了，4 人队伍到不了 |
| `EffectType` | 未接 | 触发型道具买得到但只扣钱 |

## 6 未验证清单

按审核优先级排列。前四项不通过，后面的结论都不成立。

1. **Unity 能否编译。** csproj 是手工补的，Unity 会重建。若新文件没被包含，编译会缺类型。
2. **主菜单能否进游戏。** `MainMenuBootstrap` 用 `RuntimeInitializeOnLoadMethod` 加 `sceneLoaded` 钩子运行时搭菜单，场景里没有对应组件。
3. **整局能否跑通。** 从 MainMenu 到结算，三波打完，中途不崩、不报红字。
4. **HUD 与面板是否可见。** 血条、金币、波次倒计时、商店 6 格、结算面板，以及中文字形。
5. **相机预设是否读到。** `Assets/Presets` 下两份 `.asset` 是手写 YAML，需要确认 Inspector 里字段有值。
6. **敌人、旅伴、投射物、金币的视觉区分度。** 敌人是方块、旅伴是矮胶囊、玩家是有描边的胶囊。
7. **商店键盘操作。** 方向键、Enter、R、Esc 的实际响应与摇杆死区。
8. **重开三次是否干净。** 金币、属性、队伍、保底计数、输入 Map。
9. **帧率与 draw call。** 200 敌场景的实际表现，`perf-log.md` 里这两项仍是"未测"。
10. **手感。** 移速 5、冲刺 15、相机阻尼 0.7、击退强度、hitstop 时长。
