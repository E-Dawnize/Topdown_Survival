# 项目名：Topdown Survival（2.5D 俯视角生存）

文档版本 v0.2 · Unity 2022.3.34f1c1 / URP 3D（正交斜视 2.5D）

技术实现见 [技术方案](TECH_DESIGN.md)，开发节奏见 [迭代方案](ITERATION_PLAN.md)。

> 玩法框架参考《绝区零》的「怪奇旅伴」小游戏（俯视角自动战斗 + 波次 + 商店 + 旅伴养成），角色名、数值、道具、敌人全部为本项目原创设定，不复制原作素材与具体数值。

---

## 1. 一句话定位

十五分钟内从空手捡金币，滚成一堆不断开火的旅伴和一具塞满词条的身体，然后在第五波把它们全榨干。

## 2. 核心循环

```
选探梦者(+初始旅伴) → 波次战斗(自动开火/移动/闪避) → 拾取金币与心
        ↑                                             ↓
   波次结算商店(买旅伴/道具/刷新) ← 波次结束 + 金币奖励 ←
        ↑                                             ↓
        └────────── 第3、5波BOSS → 通关 → 局外解锁 ─────┘
```

一局固定 5 波，总时长 15–18 分钟。死亡即结算，分数 = 存活时间 × 系数 + 金币 × 系数 + 击杀 × 系数。

## 3. 局内流程与节奏

| 阶段 | 时间 | 长度 | 内容 |
|---|---|---|---|
| 选人 | — | 30s | 选探梦者，看角色特性，点开始 |
| 第 1 波 | 0:00 | 180s | 教学密度，只出近战杂兵 |
| 商店 A | 3:00 | 20s | 4 个货位，可刷新 2 次 |
| 第 2 波 | 3:20 | 180s | 加入远程怪、金币怪 |
| 商店 B | 6:20 | 20s | 货位扩到 5 个 |
| 第 3 波 | 6:40 | 180s | 加入精英，末尾 BOSS |
| BOSS 结算 | 9:40 | 15s | 三选一宝箱（保底紫色） |
| 第 4 波 | 9:55 | 165s | 冲锋怪 + 地形陷阱 |
| 商店 C | 12:40 | 20s | 货位 6 个，出现祭坛 |
| 第 5 波 | 13:00 | 180s | 全怪种混编，末尾 BOSS |
| 结算 | 16:00 | — | 分数、解锁、数据面板 |

节奏原则：每 90 秒必须出现一次"变强"的正反馈（商店或宝箱）。一波内强度爬升靠金币，波间靠商店。

## 4. 操作

| 输入 | 键鼠 | 手柄 | 说明 |
|---|---|---|---|
| 移动 | WASD | 左摇杆 | 八向，无加速惯性 |
| 冲刺 | Space / 右键 | A / LB | CD 2.0s，冲刺 0.15s 无敌 |
| 主动技能 | E | RB | 角色专属，CD 8–20s |
| 手动瞄准 | 鼠标 | 右摇杆 | 覆盖自动索敌，持续 3s 后回到自动 |
| 暂停 | Esc | Start | |

自动索敌规则：锁定射程内最近的敌人；无目标不开火；优先级 精英 > 远程 > 近战。武器各自独立计算索敌，不共享目标。

手感硬指标：输入到移动响应 ≤ 1 帧；自动开火的转身不做动画过渡，直接朝向；受击有 0.1s 硬直，但不打断移动。

### 5.1 基础属性（探梦者初始值）

| 属性 | 键 | 初始 | 上限 | 说明 |

| 生命上限 | maxHP | 100 | 无 | |

| 攻击力 | atk | 0% | 无 | 全伤害乘区 |
| 攻击速度 | atkSpeed | 0% | 无 | 间隔 = 基础 / (1 + as) |
| 暴击率 | crit | 5% | 100% | |
| 暴击伤害 | critDmg | 150% | 无 | |
| 弹道数 | projectiles | 1 | 12 | 单武器独立加成 |
| 射程 | range | 6.0 | 无 | 单位 |
| 拾取范围 | pickup | 2.5 | 无 | 金币/心的吸附半径 |
| 幸运 | luck | 0 | 无 | 商店/掉落品质权重 |

| 碰撞伤害 | contact | 0 | 无 | 每 0.5s 对贴身敌人生效一次 |

### 5.2 伤害计算

```
最终伤害 = 武器基础伤害
         × (1 + 攻击力加成)
         × 暴击倍率(暴击时 × critDmg, 否则 1)
         × 距离衰减(见下)
         × (1 - 目标护甲减伤)
```

距离衰减：射程 100% 内无衰减，超出射程 120% 后线性降到 50% 为止。

伤害跳字默认只在暴击和 >20 时显示，避免糊屏。

### 5.3 成长曲线

每波开始时，所有敌人 HP ×1.9、伤害 ×1.35、速度 ×1.05（第 5 波后停止叠加）。
玩家侧：每波商店满配可得 4–6 个属性点，一局下来理论 DPS 放大 12–18 倍。这个倍数决定 BOSS 血量。

## 6. 探梦者（可选角色）

共 6 个，初始开放 3 个。

### 6.1 拾荒（初始，均衡型）

- 特性：拾取范围 +50%；每拾取 20 枚金币，攻击力 +2%（本波内有效，波末清零，可叠 50 层）
- 主动技能：磁暴，3 秒内全图金币向自己飞来，CD 15s
- 定位：教学角色，容错高

### 6.2 布袋（初始，站桩型）

- 特性：无法移动；金币与心的吸取范围为全图；商品价格 −30%；生命上限成长 +7/波；幸运 +3/波
- 代价：无法闪避，冲刺改为原地无敌 0.3s（CD 6s）
- 主动技能：开袋，把当前场上所有金币一次性吸干并额外产生 10 金币，CD 20s
- 定位：挂机刷分，波内节奏靠商店堆生存

### 6.3 咬咬（初始，碰撞型）

- 特性：碰撞伤害 +10；击杀敌人回复 2 点生命；无法获得"生命回复"属性（会被转换为护甲，1:1）
- 每 3 波（1、3、6、9 波）全队移速 +30%，持续到该波结束
- 主动技能：暴冲，向前冲 6 单位，途中碰撞伤害 ×5，CD 8s
- 定位：贴脸输出，血量是油不是命

### 6.4 卡牌王（解锁：通关一次）

- 特性：自身属性的 30% 共享给所有旅伴；每持有一件紫色以上道具，全队攻击力 +3%
- 主动技能：洗牌，随机把一件道具品质提升一级（上限金色），CD 60s
- 定位：旅伴流核心

### 6.5 针线（解锁：单局击杀 500）

- 特性：弹道数 +2，但单发伤害 −35%；攻速 +20%
- 主动技能：缝线，把 3 个最近敌人的位置连成线，线上持续 3 秒造成伤害，CD 12s
- 定位：清屏流，怕单体高血

### 6.6 紫鸣（解锁：幸运累计达 50）

- 特性：闪避上限提升到 80%；每 10 点闪避，攻击力 +2%
- 主动技能：紫雾，5 秒内闪避 +40%，期间每闪避一次对周围造成 20 伤害，CD 18s
- 定位：上限最高，前两波最脆

### 9.3 BOSS

**第 3 波 BOSS：缝线巨偶**
- HP 6000，伤害 25，无护甲
- 阶段 1（>50%）：正面扫射 + 召唤 4 个爬虫
- 阶段 2（<50%）：手臂钉在地面，形成 3 条旋转的线，线扫过造成持续伤害
- 击杀掉落：紫色保底三选一

**第 5 波 BOSS：提灯人**
- HP 24000，会随玩家 DPS 动态调整（见下）
- 全程保持距离，召唤提灯（每个提灯给 BOSS 提供 10% 减伤，需先拆）
- 血量 40% 时进入狂暴，全场黑暗 5 秒后落下 12 个 AOE
- 击杀即通关

动态血量：入场时读取玩家过去 30 秒的平均 DPS，若 DPS 超出设计区间 30%，BOSS 血量按 60% 的权重向目标值回归。避免完全体一枪秒杀，也避免硬打十五分钟。

## 10. 商店与祭坛

### 10.1 商店

- 货位：波 2 后 5 个，波 4 后 6 个，第 3 个货位固定为「旅伴/药品」
- 刷新手牌：首次 5 金币，每次 +3，每波重置
- 可卖出道具，回收 50% 价格
- 药品（一次性）：攻击药 +10% 攻击力、暴击药 +8% 暴击率、护甲药 +5 护甲、鱼油 +20 生命上限，价格 30

### 10.2 祭坛（波 4 商店后开放）

花金币换永久代价：
- 献 30 生命上限 → 得 1 件金色道具
- 献 20% 当前移速 → 得 3 个免费刷新
- 献 1 个旅伴 → 该旅伴的武器转移给玩家（玩家新增一条弹道，间隔 1.2s）

祭坛的目的：给"已经滚起来"的玩家一个必须付代价的加速器，压住终局的确定性。

## 11. 经济

金币来源：野怪 1（10% 概率 2）、精英 12、BOSS 50、波次结束奖励 `30 + 8 × 波次`。
一局理论总收入约 900–1200 金币，商店总花费 800–1100。也就是"每一波都必须做取舍"，不允许全买。

| 波次 | 收入 | 累计 | 可购买量 |
|---|---|---|---|
| 1 | 60 + 60 | 120 | 2–3 件白/蓝 |
| 2 | 90 + 80 | 290 | 3 件 |
| 3 | 120 + 110 | 520 | 4 件 |
| 4 | 150 + 150 | 820 | 5 件 |
| 5 | 180 + 200 | 1200 | 6 件 |

## 12. 局外成长

只做解锁，不做数值强化。避免新手和老玩家的强度差变成"必须刷"。

| 解锁 | 条件 | 结果 |
|---|---|---|
| 卡牌王 | 通关一次 | 新角色 |
| 针线 | 单局击杀 500 | 新角色 |
| 紫鸣 | 累计幸运 50 | 新角色 |
| 眯眼狐、羽毛笔 | 通关 2 次 | 进旅伴池 |
| 玻璃球、虹彩光盘 | 累计金币 5000 | 进道具池 |
| 难度 2–5 | 依次通关前一难度 | 敌人 HP/伤害上调，商店品质上调 |

存档：`Application.persistentDataPath/save.json`，记录累计统计、解锁标记、各角色最高分。

## 13. 表现

美术方向：低饱和灰蓝背景 + 高饱和敌人，让敌人一眼可辨。玩家和旅伴各有一圈颜色描边（玩家白、机械黄、幽灵紫、野兽橙、玩偶粉）。

打击感四件套，每个命中必须齐全：
1. 屏幕空间缩放（hitstop 0.05s，仅对暴击和精英）
2. 敌人受击闪白 0.08s
3. 攻击方向粒子 2–4 个
4. 屏幕震动：普通命中不震，暴击震 0.1 幅度，BOSS 受击震 0.2

音频优先级：敌方弹幕预警 > 命中反馈 > 拾取 > 环境音。拾取音必须随机变调 ±5%，防止连续播放刺耳。

同屏性能预算（目标 1080p 60fps，集成显卡）：敌人 200 + 子弹 400 + 粒子 300。

- 左上：生命条、护甲、闪避、金币
- 左下：旅伴头像 ×4（带 CD 环）
- 右下：主动技能 CD
- 顶部中：波次进度条 + 剩余时间
- 不显示（默认隐藏）：伤害数字统计、属性全表（Tab 展开）

商店界面：横向 6 格卡片，悬停显示详细数值变化（加粗显示"提升前 → 提升后"）。这是唯一允许玩家看到精确数字的地方。

结算：分数、存活时间、击杀、最高单次伤害、本局 DPS 曲线（折线图，横轴时间，纵轴 DPS）。

## 15. 技术概要

场景是 3D，玩法在 XZ 平面上，正交斜视相机做 2.5D 呈现，美术用简单几何体。实体是纯 C# 数据，表现层是 3D 物体。

实现细节、选型理由、性能预算全部在 [技术方案](TECH_DESIGN.md) 里，本节不再重复，避免两份文档互相矛盾。设计侧只需要记住三条约束：

1. 实体高度不超过 1 米，任何高大装饰物只能在场地边缘且不参与战斗。
2. 场地 160×160 米，战斗区 140×140，玩家和敌人都被夹在边界内。
3. 数值全部来自 Excel，改数值不需要改代码。

## 16. 开发节奏

迭代拆分与验收标准见 [迭代方案](ITERATION_PLAN.md)。游戏设计侧的完整可玩节点是：迭代 1 结束能在一个测试场里活下来，迭代 2 结束能跑完完整的 5 波，迭代 3 结束内容齐全，迭代 4 结束可以给外部人玩。

## 17. 待定与风险

- 旅伴 AI 寻路：不做寻路，只用"跟随玩家 + 距离弹性"，否则同屏 4 个旅伴的寻路开销会吃掉敌人预算
- 布袋这类"不能移动"的角色在移动端触屏操作下体验极差，需要单独做拖拽虚拟摇杆的替代方案
- 商店 6 格卡片的悬停对比在触屏上无法实现，需要改成点击展开
- 波次时长固定 180s 会让熟练玩家觉得拖，后续考虑做成"清怪达标即提前结束"
- 金色道具与祭坛叠加后可能打破终局，第 5 波 BOSS 的动态血量只能缓解不能解决，需要在迭代 3 后做一轮真人复测

## 附：设计红线

1. 不允许出现任何"只能靠刷局外数值才能过"的关卡
2. 所有随机必须可复现（一局一个随机种子，写进结算）
3. 任何一件道具都不能同时给"伤害 + 生存 + 经济"，最多两项
4. 玩家的强度增长曲线必须写在数据表里可查，不能藏在代码里
